# 已确认需求快照

> 本文件采用覆盖式存档，只保留当前已经明确确认的业务需求，不记录历史版本，也不把建议方案自动视为已确认需求。

- 最后更新：2026-07-13
- 产品名称：像素引擎（PixelEngine）
- 后端技术栈：FastAPI + PostgreSQL
- 关联设计：[business-design.md](./business-design.md)

## 1. 用户账户

- 系统需要登录和注册功能。
- 用户使用邮箱注册账户。
- 普通用户拥有独立账户和额度余额。

## 2. 角色

系统首期至少包含两种角色：

- 普通用户。
- 超级管理员。

超级管理员负责平台级配置，普通用户不能查看或修改上游渠道凭证。

## 3. 额度充值

- 用户可以购买平台额度。
- 初期兑换比例固定为 1 元人民币兑换 1 平台额度。
- 支付使用 EPay 标准协议格式。
- EPay 网关和商户配置由超级管理员填写和维护。
- 支付成功后增加用户额度。
- 支付回调和额度入账必须由后端处理，不能由前端支付结果页面直接增加额度。
- 同一个支付订单或支付回调不能重复入账。

## 4. 图片模型厂商

平台需要支持多个图片模型厂商，首批目标至少包括：

- Google 的 Banana / Nano Banana 图片模型系列。
- xAI 的 Grok 图片模型系列。
- OpenAI 的 GPT Image 图片模型系列。

厂商是模型和渠道的归属。创建渠道时必须绑定一个厂商。

## 5. 上游渠道

超级管理员可以：

- 创建多个上游渠道。
- 为渠道选择所属厂商。
- 填写渠道 Base URL 和上游 API Key。
- 手动从渠道拉取最新模型列表。
- 从拉取结果中选择图片模型加入平台模型池。

同一个厂商可以拥有多个渠道。普通用户不直接接触渠道 Base URL 和上游 API Key。

## 6. 模型池

- 只有已经加入模型池并启用的模型才能供普通用户调用。
- 平台模型需要有稳定的平台模型 ID。
- 平台模型归属于一个厂商。
- 超级管理员可以设置和调整每个模型的用户单价。
- 平台负责把用户选择的平台模型路由到该厂商下的可用渠道。

## 7. 图片生成计费

计费单位已经确定为请求图片数量。

```text
消费额度 = 模型单价 × 请求图片数量
```

- 前端提交请求时需要携带平台模型 ID 和请求图片数量。
- 后端在请求创建时保存模型单价、请求图片数量和应扣额度快照。
- 上游因协议限制拆分出的内部请求次数不影响用户计费。

## 8. 网页端模型选择

- 图片生成参数栏需要增加平台模型 ID 选择项。
- 模型选择器的数据来自后端模型池。
- 默认记住用户上次选择的平台模型。
- 已停用或已移出模型池的模型不能继续提交新请求。

## 9. 用户 API Key

- 普通用户可以创建供外部系统调用的平台 API Key。
- 创建 API Key 时必须选择一个厂商。
- 使用该 Key 时，请求只能调用其绑定厂商下已进入模型池并启用的模型。
- 后端根据厂商和平台模型选择对应渠道。
- API Key 消费用户自己的平台额度。
- 上游渠道 API Key 与用户创建的平台 API Key 是两类不同凭证。
- 用户平台 API Key 的原文只应在创建时展示一次，后端保存不可逆哈希。

## 10. 后端权威边界

以下操作必须由 FastAPI 后端完成：

- 用户身份和角色校验。
- 额度检查、扣费和结算。
- EPay 签名、回调校验和入账。
- 模型池可用性校验。
- 渠道选择和上游请求。
- 上游 API Key 保管。
- 用户平台 API Key 校验。
- 生成请求和计费记录。

普通用户前端不能通过提交任意 Base URL 或上游 API Key 绕过平台路由和计费。

## 11. Agent 模式

- Agent 多轮对话模式永久删除。
- 前端不再提供画廊/Agent 切换入口。
- 设置页不再提供 Agent API、工具轮次、Web Search 或 Agent 专属配置。
- 平台后续不为 Agent 保留兼容入口或计费方案。

## 12. 尚未确认，不纳入本快照

以下内容仍需单独讨论：

- 是否保留用户自带上游 API Key 的 BYOK 直连模式。
- 是否强制邮箱验证，以及验证码邮件服务。
- 用户图片是否上传对象存储并支持跨设备历史。
- 外部 API 的最终协议是否完全兼容 OpenAI Images API。
- 多渠道使用固定优先级、权重还是其他路由策略。
- 异步生成任务是否引入 Redis 和独立任务队列。
- 全部失败和部分失败时的退款规则及前端展示方式。

## 13. 产品对外信息

- 前端、PWA 元数据和项目说明统一使用“像素引擎 / PixelEngine”。
- 产品界面不展示原仓库、原作者、推广、外部反馈或外部版本检查入口。
- 根目录许可证文件保留，不作为产品推广内容展示。
